## 📚 项目介绍

GVB Admin 是一个基于 Vue 3 + Vite 构建的现代化博客后台管理系统。项目采用最新的前端技术栈，提供了一套完整的博客管理解决方案。

### ✨ 特性

- 🎯 基于 Vue 3 + Vite 构建，享受极速开发体验
- 🎨 集成 Ant Design Vue，提供美观的用户界面
- 📦 基于 Pinia 的状态管理，轻松处理复杂数据流
- 🚦 Vue Router 提供的路由管理，实现无缝页面导航
- 🌓 支持深色/浅色主题切换
- 📱 响应式设计，完美适配多种设备
- 🔐 完善的权限管理系统
- 🎭 用户友好的界面交互

## 🚀 快速开始

### 环境要求

- Node.js >= 18.0.0
- npm >= 8.0.0

### 安装依赖

```bash
npm install
```

### 开发环境运行

```bash
npm run dev
```

### 生产环境构建

```bash
npm run build
```

### 预览构建结果

```bash
npm run preview
```

## 🏗️ 项目结构

```
gin-vue-blog_admin
├── public/                 # 静态资源
├── src/                    # 源代码
│   ├── assets/            # 资源文件
│   ├── components/        # 公共组件
│   ├── router/            # 路由配置
│   ├── stores/            # Pinia 状态管理
│   ├── views/             # 页面视图
│   ├── App.vue            # 根组件
│   └── main.js            # 入口文件
├── index.html             # HTML 模板
├── vite.config.js         # Vite 配置
├── package.json           # 项目依赖
└── README.md              # 项目文档
```

## 🛠️ 技术栈

- **核心框架：** Vue 3
- **构建工具：** Vite

- **状态管理：** Pinia
- **路由管理：** Vue Router
- **CSS 预处理器：** SCSS
